## Key decisions (keep unless the owner changes them)

- Free and open source (GPL-3.0). No paid tier, donations, sponsors or affiliate links. Ask the owner before adding any income path.
- Design: after Arc (owner, 2026-10-23): the space colour as the frame for navigation, content on cards, the system font, Material Symbols, an accent that follows the space colour unless picked, adaptive page theme. Soft hue-tinted lift only on floating layers (menus, the command bar, sheets, toasts) and the selected row, tile or segment; no other shadows and no text glows (owner, 2026-10-23, replacing "no drop shadows"). Spring motion that settles without overshoot (owner, 2026-10-23); digits still bounce when they change (clock, to-do count, timer; owner, 2026-10-14); respect reduced motion. No sparkle "AI" icon, sentence-case labels, no middle-dot "A · B · C" strings, no arrow glyphs glued to text. Text never sits directly on a busy wallpaper without the readability layer.
- Docking: margin on `html` plus per-element translate for fixed elements. Never `transform` or `contain` on `html`.
- Header stripping (X-Frame-Options, CSP) only for sub_frame requests from the extension; never main_frame.
- New tab: a 12 x 8 grid that fits one screen (`src/shared/layout.ts`); narrow or short windows fall back to one column. Clear mode picks text tone per widget by sampling the wallpaper (`src/shared/legible.ts`, `src/ui/views/ntlegible.ts`).
- Chat: clean-room from public API docs and the MCP spec. Keys stay on the device (`aiKeys`, local storage, never synced). ChatGPT-plan access only through the official Codex CLI via the bridge. Claude and Gemini subscriptions are not supported (their terms forbid third-party use); use API keys. No identity spoofing, no reading other apps' tokens.
- Bridge: one local daemon on `127.0.0.1:47617`; the extension connects over WebSocket; web pages are refused. Pairing is by a code that `sidegig-bridge setup` prints and the owner pastes once in AI settings (decided 2026-10-14; implemented 2026-10-21: every connection proves the code).
- Icons: the site's own icon at screen resolution, measured and fitted to one visual size; bundled CC0 brand glyphs when the browser has none.
- Agent access is off by default, per device, never synced; a banner with Stop shows in every tab an agent uses (2026-10-21).
- Mail features use the browser's own Gmail session (feed and print view), never a Gmail OAuth app; mail text goes only to the model the user picked (2026-10-21).
- One rail per page: an older rail instance removes itself. Hide the page rail while a native panel is open in that window, on either side (owner, 2026-10-17).
- Design system: every style uses the tokens and components in `docs/DESIGN.md`; `test/design.test.ts` enforces it (owner, 2026-10-21: "maintain a unified UI UX design system").
- Controls: center button captions and icon/label groups across appearances. List rows (tabs, status rows, search results, reading list, stack headers) are list items and start-aligned (interpretation made 2026-10-21; owner to confirm). Wallpaper owns surface materials. Use Dock-inspired grouping and taskbar-style active markers without hover magnification or clipped badges (owner, 2026-10-17).
